# Reporting Security Issues

???+ Warning "Please do not report security vulnerabilities through public channels."
    Instead, please follow the [IBM Security Vulnerability Management guidelines](https://www.ibm.com/support/pages/ibm-security-vulnerability-management).

    - Please, visit our [security page](security.md) to learn more about the security guarantees that HElayers provide.
    - In your report please include the following information:
        - Type of issue (e.g. buffer overflow, SQL injection, cross-site scripting, etc.)
        - The configuration used and Step-by-step instructions to reproduce the issue 
        - Proof-of-concept or exploit code (if possible)
        - Impact of the issue, including how an attacker might exploit the issue
